## Stack

- Vite + React + TypeScript
- Tailwind CSS (cream palette)
- Biome for lint and format

## Get started

```bash
git clone https://github.com/knownasrazi/waitlist-kit.git
cd waitlist-kit
bun install
bun run dev
```
waitlist-kit/
  src/
    App.tsx      # app shell
    index.css    # cream tokens
  index.html
  vite.config.ts
  package.json
```
